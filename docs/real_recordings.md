# Real recordings (Track B)

Everything measured so far is composed ESC-50 audio. This track builds the
test set that decides how far those findings carry: real domestic recordings
with strong (onset/offset) labels, the same eight question types generated by
the same rules, and a hand-verification pass.

## Source: DESED (DCASE Task 4)

Two DESED subsets carry strong labels, both 10 s YouTube clips over ten
domestic classes (Alarm_bell_ringing, Blender, Cat, Dishes, Dog,
Electric_shaver_toothbrush, Frying, Running_water, Speech, Vacuum_cleaner):

| subset | clips | events | metadata (in the DESED repo) | audio |
|---|---|---|---|---|
| validation | 1,168 | 4,224 (+15 empty clips) | `data/real/metadata/validation/validation.tsv` | fetched from YouTube by the `desed` package |
| public evaluation | 692 | 2,765 | `data/real/metadata/eval/public.tsv` | Zenodo record 3588172, `DESEDpublic_eval.tar.gz`, 888 MB |

Metadata columns: `filename onset offset event_label`, tab-separated; a clip
with no events appears as one row with a blank label. Licence: the DESED code
is MIT; the clips are YouTube Creative Commons and each archive carries its own
licence file. Cite DESED (Turpault et al., DCASE 2019) and Serizel et al. (2020).

### Getting the metadata (done on 2026-09-15)

```bash
mkdir -p data/desed/metadata
for f in validation/validation.tsv eval/public.tsv; do
  gh api "repos/turpaultn/DESED/contents/data/real/metadata/$f" -q .content | base64 -d \
    > data/desed/metadata/$(basename $f)
done
```

### Getting the audio

Public evaluation, direct download (start here, 692 clips):

```bash
mkdir -p data/desed/audio && cd data/desed/audio
curl -L -o DESEDpublic_eval.tar.gz "https://zenodo.org/record/3588172/files/DESEDpublic_eval.tar.gz?download=1"
tar xzf DESEDpublic_eval.tar.gz          # check the extracted layout, then point --audio-root at the folder holding the .wav files
```

Validation, via the DESED package (YouTube, needs yt-dlp; some clips are gone or
region-locked, the importer counts the missing ones):

```bash
pip install desed yt-dlp
python -c "import desed; desed.download_real('data/desed_raw')"
```

## Import, questions, review

```bash
# timelines in the project's layout (duration 10 s when the audio is not yet on disk)
python -m ctag.real_data import --format desed --tsv data/desed/metadata/public.tsv \
       --audio-root data/desed/audio/public --duration 10 --source desed_public --out data/desed/public
# the same generator and rules as the composed benchmark; WHILE questions that
# rest on an overlap shorter than 0.3 s are dropped and counted
python -m ctag.real_data queries --timelines data/desed/public/timelines.jsonl --out data/desed/public --min-overlap 0.3
# one CSV row per question for hand verification
python -m ctag.real_data export-review --bench data/desed/public/benchmark.jsonl --out data/desed/public/review.csv
# after review: keep ok=y, apply corrected_answer, drop ok=n; blank rows never pass
python -m ctag.real_data apply-review --bench data/desed/public/benchmark.jsonl \
       --review data/desed/public/review.csv --out data/desed/public/benchmark_verified.jsonl
```

## Verification protocol

The plan targets ~300 verified clips. Review the public evaluation set first
(audio is a direct download). In the CSV, listen to the clip, read the
question, and mark `ok`: `y` if the automatic answer is right and the question
reads naturally, `n` to drop it, or `y` plus a `corrected_answer` (a JSON list
of `[start, end]` pairs, `[]` for "nothing") when the boundaries or the answer
need fixing. Speech-heavy clips produce many `Speech` questions; drop them
freely, the interest is in the other nine classes.

## Differences from the composed benchmark to state

- Events last from a fraction of a second to the full 10 s; the composed set
  caps them at 2.5 s. This is the test of the fixed-duration habit.
- Same-class events can be adjacent or fragmented (Speech especially), so
  ORDINAL questions depend on the annotators' segmentation; the review pass
  is what makes them fair.
- Overlaps are real and frequent (Speech over everything), which is what
  `--min-overlap` and the review exist for.
- Ten classes, none in ESC-50's fourteen except Dog and Cat, so the model's
  sound vocabulary is tested as well as its timing.
