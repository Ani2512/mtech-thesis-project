Over all 4,256 typed questions (empty answers counted, `ABSENT` excluded), mean
f1@0.5: untrained 0.293 (608 q), arm C 0.144, arm F 0.274, timeline 0.300. The
timeline route's apparent lead there is only that it answers empty almost
everywhere (1,217 of 1,246 gold-empty questions, 645 of 692 absent-sound questions)
while finding almost nothing.

The ordering is the reverse of the composed benchmark. The model that was never
trained on this project's data scores 0.362; every trained variant scores below
it, and the one that was best on composed audio (0.983) is worst on real audio
(0.020).

## Why: the trained models learned the composed distribution, not the task

Event-level diagnostics of the timeline adapter on the 692 clips
(`transcribe_public/summary.json` and the predictions):

| | value |
|---|---|
| event F1, label-aware (pooled) | 0.023 |
| event F1, label-agnostic | 0.148 |
| event recall / precision (pooled) | 0.036 / 0.017 |
| parse failures | 0 |
| clips transcribed as empty | 0 of 692 |
| events written | 5,892 (8.5 per clip; the gold has 2,765, 4.0 per clip) |
| predicted duration, median | **2.50 s** (gold median 0.85 s; 23% of gold events are longer than 2.5 s) |
| recall by sound | dog 0.12, cat 0.15, blender 0.02, dishes 0.01, **all others 0.00** |
| dog + cat gold events found with the right name | 89 of 681 (0.13) |

The names it wrote, over all 692 clips: cat 1,340, keyboard typing 1,131, glass
breaking 492, footsteps 455, clock alarm 436, church bells 356, dog 336, train
297, car horn 209, sneezing 165, laughing 149, siren 123, door wood knock 92,
rooster 70; then dishes 31, blender 17, and a handful of fragments. That is the
fourteen ESC-50 training classes, in a domestic recording that contains none of
keyboard typing, glass breaking, church bells, trains, sneezing or roosters. The
prompt names the fourteen classes (the closed-vocabulary variant was used, as in
training), and the model obeys the list: it never writes "speech", which is in
913 of the 2,765 gold events. Three separate habits are visible:

1. **Vocabulary.** Eight of DESED's ten classes were never in training, and the
   prompt forbids them. Recall on those is exactly zero by construction.
2. **Duration.** Every window is 2.5 s, the ESC-50 trim length, on sounds whose
   true median is 0.85 s. Even where the name is right the overlap often falls
   under 0.5. The label-agnostic F1 of 0.148 against 0.023 label-aware says that
   about six times as many windows land on *a* sound as on the *named* sound.
3. **Density.** It writes 8.5 events per clip for 10 s of audio, twice the true
   count: the generated training clips carry 6.5 events per 20 s and the model
   reproduces that rate.

Arm C at scale shows the same habits in the per-question form: predicted
centres within 1 s of a true sound only 51% of the time, duration ratio 1.56,
and "nothing" answered on none of the 1,938 questions that require it
(rejection F1 0.000). The untrained model has a duration ratio of 1.00 and a
rejection F1 of 0.595 on the absent-sound questions: its windows are the right
length and it can say nothing, which is why it wins.

The trailing check cannot help (307 spurious events removed, 0 correct, F1
0.023 to 0.024): the failure is upstream of anything that edits the transcript.

## What this is, stated for the thesis

The six-month plan (2026-09-11) said: "Expect the gap between composed and
real to be the most quoted number in the thesis." This is that number. Training
on composed ESC-50 clips with a closed fourteen-name vocabulary and a fixed
2.5 s event length gives 0.983 on the composed test split and negative transfer
to real domestic recordings. It is a result about synthetic training, not a fault
in the pipeline: the pipeline reproduces every real answer exactly from the
annotators' timelines (oracle 1.000 on all 4,948 questions), the audio files are
all present, and the model's outputs are well formed (parse failure 0).

Two caveats cut the other way. The DESED answers are automatic; the hand review
has not been done, and WHILE questions in particular depend on annotation
slivers (208 were dropped at the 0.3 s filter, others remain). And the
untrained row is on the first 700 questions, not all 4,948.

## What follows

1. **Separate the three habits.** Re-run the timeline adapter with
   `--no-vocab-in-prompt` (the open-vocabulary prompt exists) to see whether
   the vocabulary habit is the prompt or the weights. Score dog and cat alone
   with a looser overlap threshold to see whether timing survives where the
   name is known (at IoU 0.5 the 2.5 s windows fail on 0.85 s sounds even when
   centred).
2. **TEMPO's second stage: train on real data.** DESED's validation set
   (1,168 clips, strong labels, via the `desed` package) is the natural training
   half, with the 692-clip public set as the test. Mixed with the generated
   clips, open vocabulary, real durations. This is the fix the literature uses.
3. **Generate with real durations and more classes.** The composer trims every
   ESC-50 source to 2.5 s; letting durations vary and drawing from all 50 classes
   removes two of the three habits without any real data.
4. **The hand review** still decides which DESED questions are fair; the
   relative ordering above is far too large to be an annotation artefact, but
   per-type numbers on real audio should not be quoted until it is done.
